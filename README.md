# 📖 Varaq — Kitob do'koni

> *"Har bir varaq — yangi bir dunyo."*

Bu loyiha — o'zbek va jahon adabiyotining sara asarlarini bir joyga jamlagan onlayn kitob do'koni. Foydalanuvchi kategoriyalar bo'yicha kitoblarni ko'rib chiqishi, filtrlashi va savatga qo'shishi mumkin.

🔗 **Jonli havola:** [snazzy-cassata-fda28b.netlify.app](https://snazzy-cassata-fda28b.netlify.app)

---

## ✨ Asosiy imkoniyatlar

- 🏠 **Bosh sahifa (Hero)** — sayt maqsadini tanishtiruvchi chaqiruv bloki
- 📚 **Katalog** — 8 ta kitob, muqova rasmlari, muallif va narxi bilan
- 🏷️ **Kategoriya filtri** — Klassika, Zamonaviy roman, Bolalar, Tarixiy bo'limlari bo'yicha saralash
- 🛒 **Savat funksiyasi** — har bir kitobni bir tugma bosish bilan savatga qo'shish
- 🔍 **Qidiruv** — kitoblarni tezda topish imkoniyati
- 📱 **Moslashuvchan dizayn (Responsive)** — turli ekran o'lchamlarida qulay ko'rinish

## 🧠 Namoyish etilgan ko'nikmalar

| Ko'nikma | Tavsif |
|---|---|
| 🖥️ HTML/CSS | Semantik tuzilma va toza, zamonaviy interfeys dizayni |
| 🎨 UI/UX | Foydalanuvchiga qulay navigatsiya va vizual ierarxiya |
| ⚙️ JavaScript | Kategoriya bo'yicha filtrlash va savat interaktivligi |
| 🖼️ Kontent bilan ishlash | Kitob ma'lumotlari, rasmlari va narxlarini tizimlashtirish |
| ☁️ Deploy | Netlify orqali loyihani joylashtirish va nashr qilish |

## 🛠️ Ishga tushirish

```bash
# Repozitoriyni klonlash
git clone <repo-havolasi>

# Loyiha papkasiga o'tish
cd varaq

# index.html faylini brauzerda oching
```
